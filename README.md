# Парадокс Дней Рождения

> **Парадокс дней рождения** — удивительный статистический феномен: в группе из всего **23 человек** вероятность того, что **два человека родились в один день**, превышает **50%**.  
> Узнать подробнее можно в [Википедии](https://ru.wikipedia.org/wiki/Парадокс_дней_рождения).
